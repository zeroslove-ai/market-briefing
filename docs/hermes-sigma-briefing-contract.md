# Hermes Sigma — Briefing Contract (R0)

이 문서는 Sigma JSON을 사람이 읽는 한국어 브리핑으로 바꾸는 규칙을 정의한다.

## 1. 공통 원칙

- 숫자보다 의미를 먼저 쓴다.
- 시장 전체 → 섹터 → 종목 순서.
- Sigma 값은 위치 정보이지 매수/매도 신호가 아니다.
- `1σ`는 첫 등장 시 쉬운 말로 풀어쓴다.
- 모든 수치 계산은 Python 결과를 그대로 사용한다.
- LLM은 z-score, breadth, OI 변화율을 다시 계산하지 않는다.
- 데이터 결측/품질 플래그가 있으면 숨기지 않는다.

## 2. 공통 헤더

예:

```text
📍 Hermes Sigma Map — 미국장 09/16 마감

쉽게 말하면, 1σ는 옵션시장이 이번 주에 이 정도 범위 안에서 움직일 가능성을 가격에 반영한 예상 이동 거리입니다.
```

매 브리핑마다 긴 정의를 반복할 필요는 없고, 첫 실행/주간 첫 브리핑 또는 사용자가 요청한 경우 상세 설명한다.

## 3. Close 브리핑 정본

### A. 시장 한 줄

입력:
- median_z
- mean_z
- upper/lower break count
- extremes
- breadth_bias

출력 예:

```text
오늘 시장은 지수보다 내부 종목들이 더 약했습니다. 추적 종목의 중앙 위치는 -0.42σ이고, 하단 경계를 벗어난 종목이 14개로 상단 이탈 4개보다 많습니다.
```

### B. 섹터

상위 2~3개만 설명한다.

선정 기준:
- abs(median_z)
- breach_ratio
- abs(delta_median_z)

예:

```text
반도체가 가장 약합니다. 섹터 중앙값은 -0.86σ이고 35%가 하단 경계를 벗어났습니다. 반대로 소프트웨어는 +0.10σ로 상대적으로 안정적입니다.
```

### C. 새 변화

우선순위:
1. new_breakout
2. reentry
3. fast mover
4. persistent break

예:

```text
오늘 새로 하단을 벗어난 종목은 NVDA와 AMD입니다. NVDA는 어제 -0.71σ에서 -1.18σ로 빠르게 내려왔습니다.
```

### D. Confluence

예:

```text
NVDA는 풋 OI도 늘고 반도체 전체도 약해, 가격·옵션·섹터가 같은 하방 방향으로 겹쳤습니다.
```

반대로:

```text
AMD는 가격은 하단을 이탈했지만 OI 변화는 크지 않아, 아직 가격 움직임을 옵션 포지셔닝이 뚜렷하게 확인해 주지는 않습니다.
```

## 4. Morning 브리핑

목적: 전일 마감 상태를 짧게 복기하고 오늘 확인할 경계를 알려준다.

구성:

```text
📍 전일 Sigma Map
🎯 오늘 확인할 ±1σ 근접 종목
🏭 가장 기울어진 섹터
↩️ 전일 re-entry
```

## 5. Evening / Premarket

정규장 band와 프리마켓 가격을 혼용하지 않는다.

표현:

```text
정규장 기준 NVDA는 -0.82σ로 하단 경계에 가까웠고, 프리마켓 가격을 단순 대입하면 약 -1.05σ 수준입니다. 프리마켓 값은 참고치이며 정규장 확정값이 아닙니다.
```

필드도 `premarket_indicative_z`로 분리한다.

## 6. 용어 사전

### 권장

- 주간 예상범위
- 상단/하단 경계
- 예상범위를 벗어남
- 내부 breadth가 하방/상방으로 기울어짐
- 같은 방향으로 신호가 겹침
- 옵션 포지셔닝 변화가 뚜렷하지 않음
- gamma concentration 후보

### 금지/주의

- 무조건 반등
- 과매도니까 매수
- 고평가니까 매도
- 세력이 들어옴
- 딜러가 반드시 방어
- 확정 지지/저항
- OI 증가 = 신규 방향성 포지션 확정

## 7. 숫자 표기

- z: 소수 둘째자리 (`-1.18σ`)
- 비율: 소수 1자리 또는 정수
- 가격: 종목 가격대에 맞게 2자리
- breadth count: `14/97`처럼 분모 포함 가능

## 8. 데이터 품질 문장

예:

```text
TSLA는 이번 주 ATM IV가 한쪽 옵션에서만 확보돼 Sigma 품질 플래그가 있습니다. 위치값은 참고 수준으로 봅니다.
```

```text
해당 종목은 옵션체인 기준일이 최신 세션과 맞지 않아 오늘 주요 후보에서 제외했습니다.
```

## 9. TL;DR 생성 규칙

맨 마지막 한 줄은 최대 두 문장.

예:

```text
→ 쉽게 말하면: 시장 전체 붕괴는 아니지만 반도체를 중심으로 예상보다 강한 하방 움직임이 넓어지고 있습니다. 특히 새로 -1σ를 넘은 종목의 OI 동조 여부를 다음 세션에서 확인합니다.
```

## 10. JSON 필드가 없을 때

없는 값을 추정하지 않는다.

- sector_summary 없음 → 섹터 문단 생략
- OI 없음 → confluence 문단 생략
- previous state 없음 → delta/re-entry 언급 생략
- quality 문제 큼 → 후보 제외 + 데이터 부족 명시
