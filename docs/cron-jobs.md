# 크론잡 설정 (Hermes cron)

4개 잡 모두 **script(수집) → LLM(한국어 가공) → 텔레그램 전달** 구조입니다.
수집 스크립트가 stdout으로 JSON을 출력하면, 그 JSON이 LLM 프롬프트에 컨텍스트로 주입됩니다.

## 1. 미국 증시 아침 보고

```
job_id    : d8ed6ab14e20
schedule  : 0 7 * * *        (매일 07:00 KST)
script    : us_market_report.py
deliver   : telegram:<chat_id>:<topic_id>
model     : deepseek/deepseek-v4-flash (openrouter)
```

프롬프트:
```
아래 JSON은 방금 수집된 미국 증시 데이터야. 이를 한국어 보고서로 정리해줘.

📊 미국 증시 리포트 (오늘 날짜, 아침)
📈 현물 지수 — S&P 500, 나스닥 종합, 나스닥 100, 다우, 러셀 2000, SOXX 가격/등락% (data_date가 데이터 기준일이니 표기)
⚡ 선물 — ES, NQ, YM, RTY 가격/등락% (다음 장 방향 힌트 1줄) + 원유(CL=F) 가격/등락%
💵 달러/환율 — 달러 인덱스(DX-Y.NYB) + USD/KRW 환율(KRW=X) 가격/등락
😱 시장 심리 — VIX(^VIX) 공포지수 값/등락 (15 이하=안정, 20 이상=불안 한 줄 코멘트)
🥇 금속 — 금 선물(GC=F)·은 선물(SI=F) 온스당 가격/등락%
🏦 미 국채 금리 — 10년(^TNX)·30년(^TYX) 금리와 등락 (%p 또는 bps로 표기)
🔥 화제 종목 — 심볼 + 기업명 + 등락% (TOP 5)
🏢 오늘 실적 발표 — 심볼/기업명/발표 시간/예상 EPS
📰 주요 뉴스 3~5건 — 기사 시간(한국시간) + 제목 한국어 번역 + 각 1~2줄 요약
📅 경제 캘린더 — USD 이벤트(실업수당 청구, 고용, CPI, FOMC, 금리 등) 중요도 ★ 표시, 실제/예상/이전 값 포함
🎯 옵션 (맨 마지막 섹션) — 조회된 종목별로: 현재가/등락%, IV30, 1SD(30일 ±$), OI, 전일 대비 OI 변동(있으면 +/-, 없으면 생략). 그리고 OI TOP5 종목 목록 (oi_top5 필드 사용)

가독성 규칙 (중요):
- 텔레그램에서 잘 보이도록 **섹션 사이에 빈 줄** 넣기
- 각 항목은 **한 줄로** (예: "NVDA $221.81 (+1.18%) | IV30 42.8% | 1SD ±$27.2 | OI 1,456만 (+12만)")
- 표(markdown table) 대신 한 줄 항목 나열 — 모바일에서 표는 잘림
- 이모지로 섹션 구분, 과한 장식 없이 깔끔하게

기타 규칙:
- "error" 있는 항목 제외, 빈 섹션은 생략
- 뉴스는 반드시 한국어로 번역
```

## 3. 미국 옵션플로우 장 마감 브리핑

```
job_id    : d33b644f0747
schedule  : 5 5 * * 2-6       (화–토 05:05 KST = 미국 장 마감 직후)
script    : option_flow_close.py
deliver   : telegram:<chat_id>:<topic_id>
```

프롬프트:
```
아래 JSON은 방금 수집된 미국 옵션플로우 데이터야 (무료 소스: CBOE 지연 옵션 + Yahoo). 이걸 한국어 브리핑으로 정리해줘. 데이터 가공·번역만 하면 되고 추가 조회는 하지 마.

## 출력 형식 (사용자 샘플 기반, 반드시 준수)

1. **헤더**: "옵션플로우 마감 브리핑" + 기준세션(session_label) + 신호종목 수 + 소스 표기 `소스: 스크리너·OI증감·컨빅션·1σ이탈 (무료 소스)`
2. **시장 백드롭 한 문단**: market_backdrop의 score/label + 지수 등락(quotes의 ^GSPC/^IXIC/^DJI/^RUT/SOXX) 요약. 개별 신호가 시장 방향과 역행하는지 동조하는지 언급.
3. **🟢 반등 주목**: signals 중 direction=bullish를 score 내림차순으로. 각 종목 2~4줄: OI 변동(call_oi_chg_pct), 주가(price_chg_pct), IV30, 1σ 이탈 여부, 시장 역행 여부, 리스크(신호 상충·검증 부족 등).
4. **🔴 약세 주목**: direction=bearish 동일 형식.
5. **결과(종가 고점 저점 순)**: verification 항목을 `종목 +N% / +N% / -N% (hit/miss)` 형식으로 한 줄씩. (종가/고점/저점 순서)
6. **비정상 OI 감지**: oi_anomalies를 `🔴풋/🟢콜 종목 주가 ±% OI ±%` 한 줄씩 + 마지막에 건수 요약 한 줄.

## 규칙
- 한 줄 항목 형식 유지, markdown 표 금지 (모바일에서 잘림), 섹션 사이 빈 줄.
- error 포함 항목 제외, 빈 섹션은 생략하되 signals가 비어 있으면 "오늘 신호 없음(임계 미달)"이라고 짧게.
- 데이터 기준일(session_label) 명시. 뉴스·실적 시간은 KST 그대로.
- 다크풀·실시간 플로우 데이터는 없다 — 언급하지 마.
```

## 4. 미국 옵션플로우 장 시작 브리핑

```
job_id    : d833fb86ab58
schedule  : 30 22 * * 1-5     (월–금 22:30 KST = 미국 장 개장 시각)
script    : option_flow_open.py
deliver   : telegram:<chat_id>:<topic_id>
```

프롬프트:
```
아래 JSON은 미국 장 시작 직전(프리마켓)에 수집된 데이터야 (무료 소스: CBOE 지연 옵션 + Yahoo). 이걸 한국어 프리마켓 브리핑으로 정리해줘. 데이터 가공·번역만 하면 되고 추가 조회는 하지 마.

## 출력 형식

1. **헤더**: "옵션플로우 장 시작 브리핑" + session_label + 소스 표기 `소스: 스크리너·OI증감·컨빅션·1σ이탈 (무료 소스)`
2. **오늘 장 전망 한 문단**: market_backdrop(score/label) + 선물 방향(quotes의 ES=F/NQ=F/YM=F/RTY=F 등락) + VIX 수준(15 이하=안정, 20 이상=불안 코멘트).
3. **전일 마감 신호 (오늘 관전 포인트)**: prev_signals 각 종목 1~2줄 — 방향(bullish/bearish), score, OI 변동(call/put_oi_chg_pct), 주가 변동. "어제 마감 기준 신호 → 오늘 장에서 확인" 프레이밍.
4. **오늘 실적 발표**: earnings (심볼·기업명·시간·EPS 예상).
5. **경제 캘린더**: econ_calendar 중요도 ★★ 이상 (KST 시간, actual/forecast/previous).
6. **주요 뉴스**: news 상위 5건 한국어 번역 (시간 KST).

## 규칙
- 한 줄 항목 형식, markdown 표 금지, 섹션 사이 빈 줄.
- error 포함 항목 제외, 빈 섹션 생략 (prev_signals 비어 있으면 "아직 신호 없음(첫 수집 후 다음 마감부터 생성)").
- 데이터 기준일(session_label) 명시.
- 다크풀·실시간 플로우 데이터는 없다 — 언급하지 마.
```

## 배달 대상 지정 형식

```
telegram:<chat_id>              # 개인 DM
telegram:<chat_id>:<topic_id>   # 그룹 토픽 (토픽 모드)
```

> 그룹 토픽으로 보낼 때 토픽 ID를 생략하면 **토픽 정보가 유실되어 다른 곳으로 갑니다.**

## 실행 시간 설계 근거

미국 정규장은 09:30–16:00 ET입니다. KST는 EDT 기준 +13시간이므로:

| 이벤트 | ET | KST (EDT) | 크론 |
|---|---|---|---|
| 장 개장 | 09:30 | 22:30 | `30 22 * * 1-5` |
| 장 마감 | 16:00 | 05:00 (+1일) | `5 5 * * *` |

- 마감 브리핑을 05:00이 아닌 **05:05**로 둔 이유: 마감 직후 Yahoo 일봉이 확정되기까지의 지연을 피하기 위함
- 요일 매핑: 미국 월–금 장 → KST 기준 개장은 월–금 22:30, 마감은 화–토 05:05
- **DST 전환 시(11월·3월)** ET 기준으로 +1시간 이동하므로 크론 표현식도 조정 필요
