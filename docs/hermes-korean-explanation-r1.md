## 1. 독자 기준

기본 본문은 **주식 중급자**를 대상으로 한다.

가정:
- 지수, ETF, 금리, 실적, PER 정도는 알고 있음
- 옵션 IV/OI, breadth, Sigma는 익숙하지 않을 수 있음
- 숫자를 보는 것은 괜찮지만 여러 지표를 연결해서 해석하는 것이 부담스러움

따라서 전문용어를 숨기지 않는다.
대신 모든 중요 용어에 대해 **현재 시장에서 왜 중요한지**를 짧게 설명한다.

초보자도 읽을 수 있도록 별도 `쉽게 설명하면` 보조 문장을 준비한다.

## 2. 설명 기본 구조

모든 주요 해설은 다음 순서를 따른다.

1. **무슨 일이 있었나**
2. **왜 중요한가**
3. **다른 지표도 확인해 주나**
4. **반대 근거/한계는 무엇인가**
5. **다음에 무엇을 보면 되나**

예:

```text
10년물 국채금리가 8bp 상승했습니다.
→ 장기 할인율이 높아지는 방향이라 고밸류 성장주에는 부담이 될 수 있습니다.
→ 실제로 NQ와 반도체가 동시에 약하면 이 해석의 신뢰도가 높아집니다.
→ 다만 성장주가 금리 상승에도 강하다면 금리가 당일 주가의 핵심 축은 아닐 수 있습니다.
→ 다음 세션에서 10년물 상승 지속 여부와 NQ/반도체 동조를 확인합니다.
```

## 3. 설명 깊이 3단계

### A. 기본 — 중급자 본문

전문 용어 + 의미.

예:
“시장 breadth가 하방으로 기울었습니다. 지수 하락폭보다 -1σ 하단 이탈 종목 수가 빠르게 늘어 시장 내부가 표면 지수보다 취약한 상태입니다.”

### B. 보조 — 쉽게 설명하면

어려운 용어가 등장한 중요 섹션에만 1문장.

예:
“쉽게 말하면, 대표지수는 아직 크게 안 빠졌지만 안쪽 종목들은 이미 더 많이 무너지고 있다는 뜻입니다.”

### C. 심화 — 숫자 근거

필요할 때만 한 줄.

`Median z -0.52 | Lower break 18/97 | Δ lower break +7`

기본 보고는 A 중심이며 B는 중요한 개념에만, C는 핵심 후보에만 붙인다.

## 4. 용어 사전과 한국어 표현

### Basis Point / bp

**중급자:** 금리 변화폭의 단위. 1bp = 0.01%p.

“10Y +8bp”는 10년물 금리가 0.08%p 올랐다는 뜻.

**쉽게 설명하면:** 금리가 아주 작은 단위로 얼마나 움직였는지를 표현한 것.

주의:
- “금리 +8%”라고 쓰지 않는다.
- 금리가 올랐다고 모든 성장주가 반드시 하락한다고 단정하지 않는다.

### Breadth / 시장 내부 확산도

지수가 아니라 **얼마나 많은 종목이 실제로 같은 방향으로 움직이는지** 본다.

**중급자:**
“Nasdaq는 -0.4%지만 하락 종목 수와 -1σ 이탈 종목 비중이 크게 늘어 breadth는 지수보다 약합니다.”

**쉽게 설명하면:**
“대표선수 점수는 비슷한데 팀 전체 선수들은 더 많이 밀리고 있다는 뜻.”

왜 중요:
- 대형주 몇 개가 지수를 떠받치는 상황 탐지
- 지수 상승이 넓은 상승인지 좁은 상승인지 구분

### Relative Return / 상대수익률

종목 움직임에서 시장/섹터 영향을 빼고 **종목 자체 재료가 얼마나 강했는지** 보는 보조지표.

예:
- NVDA +5%
- SOXX +1.5%
- relative +3.5%p

“반도체 전체 상승보다 NVDA가 훨씬 강해 개별 재료의 영향이 컸을 가능성이 높습니다.”

### IV / Implied Volatility

옵션 가격에 반영된 **앞으로의 기대 변동성**.

높은 IV = “하락 예상”이 아니다.
상승/하락 어느 쪽이든 큰 움직임이 예상될 때 높아질 수 있다.

**쉽게 설명하면:**
“옵션시장 참가자들이 앞으로 주가가 얼마나 크게 흔들릴 수 있다고 가격에 반영했는지.”

### OI / Open Interest

아직 청산되지 않은 옵션 계약 수.

OI 증가는 관심/포지션이 늘어난 흔적이지만:
- 매수자가 누구인지
- 매도자가 누구인지
- 신규 방향성 포지션인지

공개 OI만으로 확정할 수 없다.

따라서:
“Put OI가 증가해 하방 옵션 관심이 커진 흔적”
까지 표현하고
“기관이 숏쳤다”는 금지.

### 30D Expected Move

IV30으로 계산한 약 30일 기대변동폭.

Weekly Sigma와 다르다.

“앞으로 약 한 달 동안 옵션가격이 반영하고 있는 움직임 크기”로 설명.

### Weekly Sigma / 주간 Sigma

금요일 기준 다음 주 옵션 IV로 고정한 예상 이동거리.

- 0σ = 기준점
- +1σ = 상단 예상거리
- -1σ = 하단 예상거리
- -1.2σ = 하단 예상거리보다 약 20% 더 이동

**쉽게 설명하면:**
“이번 주 옵션시장이 예상한 보통의 움직임 범위를 자처럼 그어 놓고, 지금 주가가 그 자 어디까지 갔는지 보는 것.”

중요:
- -1σ = 매수 신호 아님
- +1σ = 매도 신호 아님
- 정상범위 대비 움직임이 얼마나 특이한지를 보는 좌표

### Delta-z / Sigma 이동속도

어제 대비 z 위치 변화.

- -0.3 -> -1.1: 하방 이동이 빠름
- -1.0 -> -1.1: 이미 낮은 위치에 계속 머무름

같은 -1.1σ라도 완전히 다른 상태다.

### Re-entry

±1σ 밖에 나갔다가 다시 안으로 복귀.

“극단적 움직임이 지속되지 않고 정상 기대범위 안으로 돌아온 것.”

반드시 반등 성공/추세전환이라고 표현하지 않는다.

### VIX

S&P 500 옵션시장이 반영하는 단기 변동성 기대.

절대 수준과 변화 속도를 같이 본다.

- 15 -> 19: 극단 공포는 아니어도 위험 프리미엄 확대
- 25 -> 20: 여전히 높은 편이지만 stress 완화

### DXY / Dollar Index

달러 강약.

연결:
- 글로벌 liquidity/risk appetite
- 미국 다국적기업 해외매출 환산
- 원자재

단, 하루 DXY 움직임으로 시장 원인을 단정하지 않는다.

### Yield / 국채금리

10년물:
- 장기 성장/인플레이션/할인율 기대와 연관
- 성장주 valuation 설명에 자주 사용

30년물:
- 더 장기적인 인플레이션/term premium 맥락 보조

향후 2년물 안정 source 확보 시:
- Fed policy expectation을 더 직접적으로 설명 가능

### Sector Rotation

같은 시장 안에서 자금/상대강도가 섹터 간 이동하는 현상.

단순 하루 등락보다:
- sector relative return
- sector median Sigma
- breadth
- 연속성

을 같이 본다.

### Risk-on / Risk-off

한 자산만 보고 선언하지 않는다.

Risk-off 후보 근거:
- equities weak
- VIX up
- credit/liquidity stress (source 확보 시)
- USD stronger
- defensive relative strength

여러 축이 동조할 때만 강하게 표현.

## 5. 뉴스 한국어 설명 표준

기사 번역이 목적이 아니다.

핵심 뉴스는:

### 1) 무슨 일?
공식 사실.

### 2) 왜 중요?
주가 메커니즘.

### 3) 시장은 실제로 어떻게 반응?
종목/섹터/시장/relative return/Sigma/OI.

### 4) 다음에 무엇을 봐야 하나?
미확인 변수.

예:

```text
[NVDA] AI GPU 수출 규제 업데이트

핵심:
판매 가능한 지역과 조건이 더 제한되는 내용입니다.

왜 중요:
데이터센터 GPU의 잠재 매출시장과 장기 성장 기대에 직접 연결됩니다.

시장 반응:
NVDA -2.8%, SOXX -1.1%. 섹터보다 약했고 Sigma 위치도 -0.9σ에서 -1.3σ로 내려갔습니다.

쉽게 설명하면:
뉴스 자체도 부정적이지만, 실제 주가도 반도체 평균보다 더 크게 반응해 시장이 이 재료를 무시하지 않았다는 뜻입니다.

체크:
다음 세션에도 -1σ 아래에 머무는지와 Put OI 동조 여부.
```

## 6. 실적 한국어 설명 표준

단순 EPS 숫자 나열 금지.

### 발표 전

- 예상 EPS
- 현재 주가 위치
- 최근 5-session 움직임
- IV30
- Weekly Sigma edge
- 이벤트 중요도

해설:
“실적을 앞두고 이미 +0.9σ까지 올라와 있어 긍정적 기대가 일부 가격에 반영됐을 가능성을 염두에 둡니다. IV도 높아 옵션시장은 평소보다 큰 변동을 예상하고 있습니다.”

### 발표 후

- actual vs forecast
- revenue/guidance
- 주가
- sector relative
- Sigma transition
- OI
- official filing

“EPS beat”만 보고 호재라고 끝내지 않는다.
가이던스와 실제 price reaction을 더 중요하게 볼 수 있다.

## 7. 초보자 모드

별도 데이터를 만들지 않는다.
동일 deterministic payload를 **다른 문체로 설명**한다.

초보자 모드 규칙:
- 한 문장에 전문용어 1개 이하 권장
- 처음 나온 용어 즉시 풀어쓰기
- 숫자를 줄이고 방향/의미 중심
- 매수/매도 지시 금지
- “왜 중요한지” 반드시 설명

예:

중급자:
“반도체 median z가 -0.86σ이고 lower-break ratio가 35%로 확대됐습니다.”

초보자:
“반도체 종목들이 이번 주 예상 하단범위 쪽으로 몰리고 있고, 3개 중 1개 정도는 이미 그 범위를 벗어났습니다.”

## 8. 사용자 선택 모드

향후 config:

```json
{
  "explanation_mode": "intermediate",
  "include_beginner_help": true,
  "detail_level": "normal"
}
```

mode:
- `beginner`
- `intermediate` (기본)
- `compact_expert`

`include_beginner_help=true`이면 중급자 본문 아래 중요한 개념에만 “쉽게 말하면”을 추가한다.

## 9. 금지 표현

근거 없이:
- 무조건 오른다/내린다
- 과매도라 반등한다
- 세력이 매집
- 기관이 숏
- 딜러가 지지
- 이 뉴스 때문에 하락
- 1σ니까 싸다

대신:
- 같은 방향으로 나타남
- 동조
- 정합적
- 촉매 후보
- 상대적으로 강/약
- 추가 확인 필요

## 10. 출력 목표

Hermes 한국어는 금융 번역체가 아니라 **한국 투자자가 실제로 읽는 자연스러운 해설**이어야 한다.

나쁜 예:
“시장 배경은 slight bearish이며 confluence가 나타났습니다.”

좋은 예:
“시장 내부는 약세 쪽으로 기울었습니다. 특히 반도체에서 하단 예상범위를 벗어난 종목이 늘었고, 일부 종목은 Put OI 증가도 같이 나타났습니다.”

영문 내부 enum은 최종 사용자 메시지에 그대로 노출하지 않는다.
